## 4. 定稿优先顺序

1. 先确定地域、季节／学年、User出镜方式、三女主外观基础，防止制服与场景重画。
2. 整合第三章尾声、校对重复台词，补笔记本交接和最后答复期限。
3. 再校对学姐学籍、两场音乐会与法国创作项目，保证后半剧情可理解。
4. 完成Claude／GPT／Normal End的独立剧本以后，再增加相应场景与素材；不得将互斥结局顺接。
