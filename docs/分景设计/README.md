## 拆解原则与范围

1. **保留原稿事实。** 地点迁移、角色独处反打、独立告白都明确拆场；未写出的Claude／GPT／Normal End不代为虚构。
2. **制作建议单独标识。** 镜头、表情、构图、灯光、声音与部分未明确地点的调度是本版新增建议；不把这些当作原作者既定设定。
3. **重复不重复演。** 第三章两段尾声按较长版骨架合并，保留较短版独有约定。这是本版明确提出的整合方案，原稿文件未被删改。
4. **先普通演出，再重点CG。** 背景、人物、道具、界面分开，可以复用房间和表情；419拍不意味着419张绘图。
5. **一个最终菜单，四个独立出口。** 原稿此前没有明确剧情选项，不额外发明好感度系统。已有完整可制作范围是共同线＋DeepSeek线。

这种背景、角色属性、转场与剧情节点分开的方式，符合视觉小说引擎的常用组织方式；Ren’Py官方文档分别说明了[图片与图层、角色属性及转场](https://www.renpy.org/doc/html/displaying_images.html)、[选择菜单](https://www.renpy.org/doc/html/menus.html)和[标签与跳转](https://www.renpy.org/doc/html/label.html)。本次借用这些成熟的内容组织方式，尚未替项目锁定引擎。

## 主线与情绪曲线

| 阶段 | 玩家应感受到什么 | 制作重点 |
|---|---|---|
| 相遇与误认 | 轻喜剧、偶然、被故事吸引 | 天台与笔记本可辨；Claude告白的因果需补强 |
| 努力与靠近 | 改变需要行动，帮助慢慢变成关系 | 成绩／草稿是可见成长，母亲眼泪是自发转折 |
| 文化祭 | 四人合作最快乐、最想留住的时刻 | 同一舞台与合影成为后续回忆基准 |
| 分别与异地 | 喜欢仍在，分享生活的能力逐渐减弱 | 输入删除、日期间隔、空琴凳，而非重复哭戏 |
| 三年重逢 | 每个人都已成长，旧问题不能再拖 | 三种感情分别有自己的诉求与边界 |
| 最终抉择 | 决定意味承担失去，不能由别人代答 | 期限、铁路栏杆、明确四路入口 |
| DS线确认 | 说喜欢必须先结束旧的悬而未决 | 正式分手和回应学姐是必须演出的内容 |
| 赴法与暂别 | 两人仍不完美，需要学会尊重选择 | DS反问男主替人决定，保留长谈与共同决定 |
| 重逢与兑现 | 相爱来自现在的再次选择，梦想也实现 | 四年后形象一致；笔记本与《候鸟》闭环 |

## 接下来的制作顺序

1. 先核对会直接影响画图的四项：世界地域、时间季节、三女主基础外观、User露脸规则；问题和最小建议已写进连续性表。
2. 以序章＋第一章作为第一段完整可玩内容的制作范围。先角色设定与BG01，再分镜草图和CG01；同时验证文字框遮挡、表情切换、名字揭晓。
3. 根据样板逐场将“节拍”展开为镜头与对应原句，绘制背景／立绘／CG的正式任务单；每张记录所属分景与人物时期。
4. 素材和序章脚本形成最小可玩段后，再推进第二章与文化祭；保留已经工作的素材与流程，逐层加入成年阶段和DS结局。
5. 另三条个人路线要先完成正文，再拆景和扩充素材。当前不为未写结局批量画CG。

## 数据与维护

- 原始文本：[未抵达的心意.md](../../未抵达的心意.md)。源行号以当前版本为准，结构化数据记录SHA-256，便于知道后续原稿是否变化。
- 分景明细与`scene_data.json`由[build_preproduction.py](../../tools/build_preproduction.py)中的制作记录生成；修改场景内容时先改生成器再运行，避免重新生成覆盖手工编辑。
- 美术表、连续性表与分镜样板独立维护。新增资产编号时同步检查分景引用。
- 重新生成：在项目根目录执行`python tools/build_preproduction.py`，只重写八章分景、索引和JSON，不改原稿与其余文档。
- 目前没有游戏代码、图像或音频成品。所有资产数量为计划清单，不能当作已经制作完毕。
