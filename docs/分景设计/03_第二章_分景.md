## C2-01｜停滞的电影研究社

- 原稿：[原稿 L440–L509](../../未抵达的心意.md)。
- 时间／空间：放学后；高中电影研究社。
- 出场：User、DeepSeek。
- 剧情作用：交代创作的现实起点，给整理后的活动室建立对照。
- 情绪过程：好奇兴奋 → 手忙脚乱 → 决定行动。
- 背景：BG04-dust-day。
- 画面资产：PR03旧摄像机；PR04三脚架；DeepSeek制服：兴奋、惊慌、嘴硬。

**演出节拍**

1. **C2-01-B01** 空镜扫过落灰桌椅、旧海报、器材柜；人物随后入画。
2. **C2-01-B02** DeepSeek逐一查看器材，男主提醒小心；保持轻快节奏。
3. **C2-01-B03** 三脚架倒下用叠层旋转或切局部图；响声后双方短暂停顿。
4. **C2-01-B04** 她辩解“自己倒的”，提出一个人演所有角色；表情承担笑点。
5. **C2-01-B05** 男主提出先整理、再招人；同框留出空椅子，埋下未来成员。

**收束与承接：** 社团线暂缓，切向男主学业；灰尘差分只首次使用，布局固定。

**连续性：** 无新增连续性问题。
