# 第一章：分景明细

说明：剧情事实来自原稿；镜头、表情调度、音响和素材划分均为制作建议。背景编号见《美术资产表》，连续性编号见《连续性与定稿事项》。

<a id="c1-01"></a>
## C1-01｜寻找的人与眼前的人

- 原稿：[原稿 L146–L215](../../未抵达的心意.md)。
- 时间／空间：次日放学后；操场及单杠附近。
- 出场：User、Claude、同学（声音）。
- 剧情作用：让错误信息引出Claude，明确她和天台少女外貌不同。
- 情绪过程：期待 → 怀疑 → 被拒后的冲动。
- 背景：BG02-evening。
- 画面资产：Claude制服：审视、不耐烦；单杠保留在背景一侧。

**演出节拍**

1. **C1-01-B01** 操场远景；用同学声音转述“会不会是Claude”，无需给同学独立立绘。
2. **C1-01-B02** Claude入画：橙发、发饰、整洁制服；男主注意到发色不符，误认动机保留疑点。
3. **C1-01-B03** 她察觉注视，询问来意；站位靠边、视线斜向男主。
4. **C1-01-B04** 男主问天台，她否认并认为是搭讪；表情转不耐，侧身准备离开。
5. **C1-01-B05** 男主想起同学的单杠玩笑，目光移向背景单杠。

**收束与承接：** 同一背景继续下一场；不要用换地图掩盖男主冲动。

**连续性：** ISS01：男主已经看出发色不同仍告白，动机不足，需补心理桥接。

<a id="c1-02"></a>
## C1-02｜单杠上的告白

- 原稿：[原稿 L216–L277](../../未抵达的心意.md)。
- 时间／空间：紧接上一场；操场单杠。
- 出场：User、Claude、围观学生（剪影／环境音）。
- 剧情作用：建立名义恋人关系，并埋下男主未认真承担承诺的问题。
- 情绪过程：荒唐紧张 → 尴尬 → 意外成立关系。
- 背景：BG02-evening。
- 画面资产：CG02可选；Claude制服：惊讶、脸红、嘴硬；User是否露脸依ISS09。

**演出节拍**

1. **C1-02-B01** 男主叫住Claude；她回头，操场环境声逐渐降低。
2. **C1-02-B02** 三次引体向上分三屏说出“请／和我／交往吧”；以喘息和节奏形成笑点。
3. **C1-02-B03** 拉远或切CG02：单杠与橙发少女形成两侧构图；围观用小面积剪影。
4. **C1-02-B04** Claude震惊转脸红，说两人不熟；停顿后答应试着交往。
5. **C1-02-B05** 男主旁白确认自己意外有了女朋友；以DeepSeek找不到笔记本的画外对白作尾钩。

**收束与承接：** 下一场回到真正的笔记本主人；恋爱状态从此为“User与Claude交往中”。

**连续性：** ISS01同上；DeepSeek另一栋楼找本子的短句可黑屏呈现，不必新增教室背景。

<a id="c1-03"></a>
## C1-03｜归还笔记本

- 原稿：[原稿 L278–L347](../../未抵达的心意.md)。
- 时间／空间：几天后下午；高中图书馆。
- 出场：User、DeepSeek。
- 剧情作用：从偶遇走向创作伙伴，首次把两人的梦想连接。
- 情绪过程：失落 → 惊喜 → 被理解的兴奋。
- 背景：BG03-day。
- 画面资产：PR01；DeepSeek制服：沮丧、惊喜、害羞、期待。

**演出节拍**

1. **C1-03-B01** DeepSeek趴桌沮丧；笔记本从主观画面下方递入。
2. **C1-03-B02** 她认出男主、抱紧笔记本；亮起笑容，图书馆仍保持安静音场。
3. **C1-03-B03** 男主承认读过故事；她短暂羞窘，等待评价。
4. **C1-03-B04** “如果拍成电影”触发她靠近追问；镜头轻推，强调被认真对待。
5. **C1-03-B05** 双方明确“她写／他拍”的约定；以笔记本置于两人之间收束。

**收束与承接：** 下一场带来大量剧本；不要提前把创作约定写成恋爱承诺。

**连续性：** 无新增连续性问题。

<a id="c1-04"></a>
## C1-04｜想飞的鲸鱼与第一次合作

- 原稿：[原稿 L350–L435](../../未抵达的心意.md)。
- 时间／空间：次日下午16:30；高中图书馆。
- 出场：User、DeepSeek、管理员（声音）。
- 剧情作用：建立DeepSeek想象力、小鲸鱼母题及社团需求。
- 情绪过程：热情分享 → 相互认可 → 喜剧收束。
- 背景：BG03-day。
- 画面资产：PR02鲸鱼草图；稿本堆叠叠层；DeepSeek制服：得意、疑问、开心、窘迫。

**演出节拍**

1. **C1-04-B01** 大摞笔记本落到桌上；男主反应与她得意表情交替。
2. **C1-04-B02** 插入鲸鱼草图：“星星可能也是大海”；纸面字迹后期制作。
3. **C1-04-B03** 男主读出结构问题，但被画面打动；用旁白与翻页声展示判断。
4. **C1-04-B04** 提出演员、器材和剧本修改需求；讨论去电影研究社。
5. **C1-04-B05** 她兴奋站起被管理员提醒；缩小动作、低头道歉，回归温暖日常。

**收束与承接：** 以约定去电影社结束；鲸鱼挂件到DS-09必须能看出同源。

**连续性：** 无新增连续性问题。
