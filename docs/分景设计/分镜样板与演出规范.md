# 分镜样板与演出规范

制作拆解 v0.1｜2026-10-18。下列四场展示正式分镜的颗粒度，供下一阶段逐场展开使用。镜头不是新增情节，台词仍回原稿读取；不在此重写整部剧本。

## 1. 场、节拍、镜头、图片的关系

一个场可以有多拍，一拍可以切两个镜头，同一张背景又可裁出多个镜头。一个镜头也可以持续数屏对话。只有画面内容无法通过已有背景、立绘与道具层表达，才新增图片。

例如：P-01有7个演出节拍，下表拆成10个镜头，仍只需一个天台底图、一套DS制服立绘、笔记本叠层和一项重点CG。短推镜、表情变化、输入删除不增加背景数量。

台词以玩家点击推进为默认。表中的“停顿”只指关键演出点，不给所有对白强制计时；需支持自动播放、跳过与历史回看。转场一般克制，惊吓和眼泪不能反复用全屏抖动替代。

## 6. 声音与转场统一规则

| 声音类别 | 叙事作用 | 代表位置 |
|---|---|---|
| 校园轻快主题 | 冒失、相遇、创作热情 | P-01、C1-04、C2-01 |
| 学习／成长主题 | 坚持与被支持 | C2-04、C2-09、C4-09A |
| 钢琴主题 | Claude的陪伴与难以表达 | C3-03、C3-08、DS-03 |
| 四人合奏主题 | 最快乐时刻与之后的变化 | C3-06、C5-12A；同主题可改编克制版 |
| 等待／冬日主题 | 异地消息、未发出的想念 | C4-08、C5-07各场 |
| 告白主题 | 清楚表达，但按回应改变配器 | C4-12悬而未决、DS-05回应、DS-12成熟重逢 |
| 分别主题 | 机场与暂别，允许不同情绪 | C4-06B偏失去，DS-09偏走向未来 |
| 终曲主题 | 创作约定与日常相伴 | DS-13B、DS-14B |

这8类是拟制作原创音乐的功能需求，当前没有对应完成的音频。铃声、纸张、键盘、广播、车轮、列车、掌声等环境音独立于BGM。音乐高潮不覆盖对白；告白问题后的静音与停顿同样是演出。

**记忆转场：** 已发生的文化祭、天台、课桌等复用真实已制素材，采用短淡入／低饱和或轻框线区分。不能用尚未发生的亲吻CG当回忆。消息里的想象另标“想起／想象”，不自动成为亲历事实。

**同场切换：** 一场连续对白只变表情和站位；不同地点、另一人独处、隔日则清楚换背景或时间字卡。新时间字卡可以后期文本制作，不需单独生成图片。

## 7. 后续每场分镜记录模板

```text
分景ID：与scene_data.json一致
原文范围：开始行—结束行，保留原句顺序
镜头ID：分景ID-S01，所服务节拍为B01
入口状态：时间、地点、关系、道具保管方
画面：景别、角色站位、视线、前景／背景
动作：谁先做什么、何时换表情、何时退场
文字：原稿台词／旁白；改写另标版本，不混进原文
声音：环境音、BGM进入／退出、具体触发
素材：已有资产ID、新增需求、允许裁切／差分
出口状态：新增信息、关系变化、道具交接、下一场
检查：人物时期、同空间结构、道具外观、信息视角、阅读可达性
```

分镜完成后再整理逐张绘图提示词：每张包含固定人物设定引用、场地设定引用、主动作、镜头、光线、所需差分和禁止漂移项。尚未确定的人物外观不写成既定提示词。
