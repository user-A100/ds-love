## 演出约定

背景/CG按1280×720舞台显示；人物保持比例并统一至700像素高；道具单独叠层，最长不超过420×290像素。CG切镜会清除立绘与道具，恢复背景后再按本场服装入场。手机消息和邮件不自动召出远端角色。序章未知少女仍使用“？？？”名牌，姓名在笔记本揭晓。

已接入高中、大学冬装、成年工作装、四年后春装/首映装。DS-06～09缺少大学春装时只用环境与已有道具承接正文，避免错用高中制服或四年后的成熟形象。大学夜景、春季公园及高中图书馆傍晚等缺失差分暂复用同地点图片，并在覆盖清单标出；尚不能视为全美术最终验收。DS-01～09进一步缺口仍以 [复用与补充清单](../DS线复用与补充清单.md) 为准。

原图不改绘、不裁切，145张运行时PNG与源文件一致。道具上的可读文字保留在原对白中，未把占位文字烘焙进图片。Claude/GPT/Normal 三条尚未编写的路线仍保留原入口与提示，不凭美术资产补写剧情。
