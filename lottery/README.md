# 未抵达的心意 · 幸运抽签

服务于游戏活动的独立抽奖网站，不依赖 Galgame 仓库、Ren'Py 或后端。图片已保存在本项目 assets/ 中。

双击 index.html 即可使用，或在本目录运行 `python -m http.server 8010`，打开 http://localhost:8010 。部署时将整个目录交给静态网站托管即可。

- 1–100 等概率抽取，不放回，抽完自动停止。
- 当前浏览器自动保存进度；不同设备和地址不共享奖池。
- 可导出 CSV、全屏投屏；重置前要求确认。
- 支持 Web Locks 时，同一地址多个标签页串行抽取。
- 无法写入浏览器存储时，当前页面保留本轮内存进度，并提示关闭前导出。

横屏展示时，舞台与签池自动适配屏幕高度，抽签按钮、100 个号码和相遇记录同屏显示，历史记录在面板内滚动。推荐使用 1280×720 或更大的横屏；将浏览器窗口拖到第三块屏幕后点击“全屏展示”（或按 F11）。游戏与海报分别在另外两块屏幕打开即可。

人物背后与页面背景使用 `assets/rooftop.png`（项目自绘春日天台，来源为游戏仓库 `assets_src/backgrounds/rooftop/bg_rooftop_spring_day_v001.png`），不再使用引擎默认校园图。替换此文件即可更换两处背景。角色图片复用游戏现有素材；署名和角色来源见 [assets/NOTICE.md](assets/NOTICE.md)。第三方图像不属于统一开源代码许可证覆盖的内容。
