# 终章全量美术包

范围：DS-10～DS-14B，共7个分景、34个演出节拍。依据 `docs/分景设计/08_DeepSeek线_分景.md`，覆盖四年成长、文学改编交流会、再次相爱、共同改编、首映后台、成年日常与最终天台。

计划共27项：6张背景、10张透明立绘与表情、7张完整CG、4组透明道具。保留原有最终天台6项，新增21项。实时完成数量以 [制作状态](LIVE_STATUS.md) 和 [校验清单](manifest.json) 为准。

- [逐分景、逐节拍预览](scenes.html)：按剧情顺序展示全部34个节拍，普通对话用背景、透明立绘和道具组合，重要互动使用完整CG。
- [全资产画廊](index.html)：查看每张原始PNG。
- [节拍覆盖清单](scene-coverage.json)：列出每个节拍的资产ID和文件是否齐全。
- [完整提示词及参考](../../docs/art/ending/production-plan.json)：每张图的用途、引用关系与生成提示词。

对白、聊天、名单、《候鸟》片名、日历、版本号和通关菜单由游戏文字层排版。画廊用于画面覆盖审查，不替代脚本演出和正式游戏接入。男主保持局部、背肩或主观视角，不设定正脸。没有补写婚姻、孩子、奖项或另外两位女主参加首映。

使用内置 imagegen 逐项生成；原始PNG保留实际尺寸、透明通道和字节，未强行缩放、裁切或重编码。角色身份、鲸尾、发饰左右与旧蓝笔记本沿用现有基准；成熟日常装和首映装各自建立基准。人物来源与署名见 [角色参考说明](../characters/README.md)。

`trials/` 中的带人物背景初稿和错误主角的独立工作初稿已弃用，不进入画廊、分景映射或资产完成数量。接吻CG采用修正头颈比例的 `cg19_park_short_kiss_v002.png`；v001保留作修订记录，不重复计数。

重建清单与预览：在仓库根目录依次运行 `python tools/build_ending_scenes.py` 和 `python tools/update_ending_manifest.py`。更新全项目本地统计：`python tools/audit_art_progress.py --working-tree`。

完成后请将原图、提示词、清单、分景预览和统计一起上传到GitHub。
