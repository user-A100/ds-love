# 第一幕美术资产包

范围：序章 P-01《天台上的少女》及第一章 C1-01～C1-04，从天台初遇到图书馆第一次合作。

本包由内置 imagegen 连续生成，各图复用已生成的角色、制服、场地与道具参考。原始 PNG 保留；背景、立绘、道具与完整 CG 分开存储，网页预览时才按镜头组合图层。生成提示词逐图存入 [docs/art/act01/prompts](../../docs/art/act01/prompts/)。

## 查看整幕

打开 [index.html](index.html) 查看连续分镜与全资产画廊。页面无需联网，可用左右方向键切换镜头、空格播放 / 暂停，或点击“连续播放”。全部 30 个演出镜头按原拆分顺序排列；复用资产不会重复计为新图。

预览的镜头标题用于识别演出内容，不代替原稿对白。图书馆的普通站姿层仅用于表情与色彩检查；坐姿、递本与桌面互动由完整 CG 展示。

文件尺寸、SHA-256、透明通道检查、逐张提示词、参考关系与 30 镜头映射见 [manifest.json](manifest.json)。所有图为美术试制版本；生成画幅保留实际尺寸，未强行缩放到 1920 × 1080，尚未接入游戏脚本。

## 连续性基准

- DeepSeek：蓝眼睛、深蓝至浅蓝渐变长卷发、呆毛、鳍状耳部与青蓝发结、蓝色鲸尾；制服为深蓝金边外套、米白衬衫、浅蓝领结、深蓝及膝百褶裙、白袜与深蓝鞋。
- Claude：橙色长发、琥珀色眼睛、人物左侧（观众右侧）的花形发饰；同校制服，领结为琥珀金色。
- 天台：左侧内侧矮墙、右后方楼梯门、外围安全栏杆；午后左上方光照。碰撞是内侧矮墙上的小落差失衡。
- 图书馆：左窗、后方书架、右后方门、浅木双人桌；同一光向，通过时刻和道具变化复用。
- PR01：浅蓝布面 A5 本、深蓝左书脊、米白纸边与姓名标签。普通道具版标签留白；姓名揭晓 CG 中出现 DeepSeek。
- User：主观手部、背影或局部身体，不固定正脸。所有角色穿着普通完整制服。

## 参考来源与维护

角色原型来自用户指定参考及 ai-girls 收录的 ZipZipPipe 形象；原图、作者、来源与许可核验信息继续保存在 [角色参考目录](../characters/README.md) 和 [上游使用声明](../characters/sources/ai-girls/NOTICE.md)。生成制服改编与 CG 不抹去原型来源，也不改标原图许可。

重建画廊：在游戏仓库根目录运行 `python tools/build_act01_gallery.py`。此脚本只读取资产清单并生成 HTML，不修改任何图像。场景文本仍以工作区 `docs/分景设计/` 与原稿为准。

完成后记得把源图、提示词、清单和画廊一并上传到 GitHub。
