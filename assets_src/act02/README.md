# 第二幕背景资产包

范围：第二章《重新开始》C2-01～C2-11。共六处场地、十张入选背景，使用内置 imagegen 生成；原始 PNG 保留，尚未接入游戏脚本。

打开 [index.html](index.html) 查看背景画廊及 11 个分景的连续背景预览。原始图片都在 [backgrounds/](backgrounds/)，实际尺寸、SHA-256、提示词及引用关系见 [manifest.json](manifest.json)。

| 场地 | 差分 | 用途 |
| --- | --- | --- |
| BG04 电影研究社 | 落灰／放学后 | C2-01 |
| BG05 教室 | 日间柔阴光、放学傍晚、晚自习 | C2-02、C2-07～C2-10 |
| BG06 教学楼花坛长椅 | 阴天 | C2-03 |
| BG07 User 高中家中书桌 | 日、夜 | C2-04；C2-06 暑假学习蒙太奇 |
| BG08 校内走廊 | 日、黄昏 | C2-05～C2-06 |
| BG09 Claude 高中卧室 | 夜 | C2-11 |

教室、书桌、走廊的时段差分引用各自底图，只改天气及照明。同场景跨多个分景复用，不重复计作新场地。底图无人、无对话界面、无可读剧情文字；成绩单、草稿、手机、两份蛋糕及人物均需独立叠层。

教室与花坛的初稿直射阳光过强，各执行了一次定向调光；初稿留在 `trials/`，不计入十张入选背景。对应修订提示词为 `docs/art/act02/prompts/*.refinement.txt`。所有图片未经裁切、缩放或重编码。

布局与使用约束见 [绘图任务单](../../docs/art/act02/绘图任务单.md)，完整提示词集见 [production-plan.json](../../docs/art/act02/production-plan.json)。第一幕背景只作为同校园材质及画风参考，未修改原文件。

重建校验清单与预览：在仓库根运行 `python tools/build_act02_gallery.py`。该脚本复用第一幕画廊模板，只读取图像做校验。

完成内容上传 GitHub 时，请包含背景原图、提示词、清单、预览及构建脚本。
